# Overview

In Module 02, we learned how Machine Learning algorithms such as Decision Tree, Random Forest, SVM, Logistic Regression and KNN learn patterns from historical data.

Although these algorithms are powerful, they still have limitations.

For many real-world problems such as:

- Image Recognition
- Face Detection
- Speech Recognition
- ChatGPT
- Self-Driving Cars
- Medical Image Analysis

traditional Machine Learning is not enough.

These problems require models capable of learning extremely complex patterns automatically.

This is where **Deep Learning** comes in.

Deep Learning is one of the most important branches of Artificial Intelligence and powers many modern AI applications.

---

# Why Deep Learning?

Traditional Machine Learning often requires humans to manually decide which features are important.

Deep Learning automatically learns useful features directly from the data.

Instead of manually engineering features,

we train a Neural Network to discover them.

# What Makes Deep Learning Different?

Machine Learning

```text
Data

↓

Feature Engineering

↓

Algorithm

↓

Prediction
```

Deep Learning

```text
Data

↓

Neural Network

↓

Learns Features Automatically

↓

Prediction
```

This ability to learn features automatically is what makes Deep Learning so powerful.

# Key Takeaways

- Deep Learning is a subset of Machine Learning.
- Neural Networks are inspired by the human brain.
- Deep Learning automatically learns features from data.
- TensorFlow and Keras are the most widely used Deep Learning frameworks.
- Deep Learning powers modern AI applications such as ChatGPT and autonomous vehicles.
