# AI Loan Eligibility System (Deep Learning)

## Project Overview

This project is the production implementation of the Loan Eligibility Prediction System built during **Module 03 – Deep Learning**.

Unlike the learning examples, this application follows a production-style folder structure and engineering practices.

---

# Objectives

- Predict loan eligibility using a Deep Learning model.
- Train the model using TensorFlow/Keras.
- Save and reuse trained models.
- Expose prediction APIs.
- Build a user interface.
- Containerize and deploy the application.
- Integrate into Mohan's AI World.
